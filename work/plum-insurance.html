01

The problem

Every cash-deposit (CD) statement across 800 accounts was reconciled by hand. The work was repetitive and slow, and endorsement data was accurate only 45% of the time, so errors surfaced late and leadership had no single view of what was wrong.

02

The insight

Reconciliation is mostly a fixed set of checks. If the checks are written down as logic, software can run them on every statement, and an AI model can catch the discrepancies that do not fit a simple rule.

03

What I did

Automated CD statement processing across 800 accounts, saving an estimated ₹50 lakh a year. Defined the discrepancy-detection logic and a validation framework using the OpenAI API, lifting endorsement accuracy from 45% to 70%. Built an interactive leadership dashboard with Claude and GitHub Copilot that shows issues in real time and cut manual reporting effort by 60%.

THE CORE IDEA

Most reconciliation is rule-following. Encode the rules, let a language model flag what breaks them, and send people only the exceptions, with leadership seeing every open issue in one place.
