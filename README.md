# ss756.github.io

Personal site of Suyash Singh: AI, business analytics, sales and marketing.

Plain HTML, CSS and JavaScript, served by GitHub Pages. No build step.

- `index.html`: homepage
- `work/`: case studies (pricing engine, Nat Habit, Plum Insurance)
- `assets/`: logo, images, film, `site.js` (scroll reveals and counters)

Preview locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
